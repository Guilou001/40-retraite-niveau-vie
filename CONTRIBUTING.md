# Contribuer

Une correction doit préciser la question, les données concernées et son effet sur les conclusions. Pour une formule, ajouter un exemple dont la réponse est connue indépendamment du programme. Pour une modification de protocole, conserver les paramètres précédents et déclarer la nouvelle spécification.

```bash
uv run ruff check .
uv run ruff format --check .
uv run pytest
```

Les changements de résultats doivent être accompagnés des tables, des figures et du rapport régénérés. Ne pas ajouter de clé, de fichier personnel ou de données dont la redistribution n’est pas autorisée.
